Audit baseline: checkpoint `3e2f95b5`, 2026-09-21. Phase 4 is **open**.

A classification is a product requirement/disposition, not a passing result. `Required` and `Redesigned equivalent` rows have executable acceptance scenarios below; existing code or a matching command string is only implementation evidence. Unless a named test/run is recorded, acceptance is **unverified**. `Missing` and `Present but behaviorally degraded` remain required repair work. No feature is silently retired.

Sources below are relative to `static/js/`; React owners are under `ui/src/`. All runtime acceptance uses an isolated profile and port. The live daemon must not be deployed, stopped or restarted.
