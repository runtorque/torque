---
description: Rename the current Loom agent
allowed-tools: mcp__loom__loom_name
argument-hint: <name>
---

Rename the current agent using the loom_name MCP tool.

$ARGUMENTS is the new name. It should be short and in kebab-case (e.g. "fix-auth-bug").

If $ARGUMENTS is empty, ask the user what they'd like to name the agent.
