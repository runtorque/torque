    Loom Docs¶

    Loom is an iTerm2 Toolbelt plugin for organizing AI agents and terminal sessions in a visual grid. This page is the front door to the docs: start with setup if you're new, then jump to the area that matches what you want to do.

    Start here¶

    • Getting Started — install Loom, launch it, and create your first group, agent, and terminal
    • Concepts — learn the basic vocabulary in plain language: groups, agents, terminals, broadcasts, and actions
    • CLI Reference — use Loom from the command line once the UI basics are familiar

    Common paths¶

    I want to set up Loom and start using it¶

    • Getting Started
    • Concepts
    • Agents & Sessions
    • Group Settings
    • Keyboard Shortcuts

    I want to manage work across agents¶

    • Workflow Guide — follow the normal path from task creation to dispatch, handoffs, schedules, and completion
    • Task Board — create tasks, organize lanes, and dispatch work
    • Task Lifecycle — see how tasks move through Loom
    • Worktrees — isolate changes per agent in separate git worktrees

    I want reusable prompts, templates, or pipelines¶

    • Actions & Templates — define action prompts, variables, and transitions
    • Agent Templates — save reusable agent launch presets

    I want Loom to coordinate the work for me¶

    • Weaver — Loom's orchestrator agent for dispatching work, tracking progress, and asking for human input when needed

    I need commands, settings, or help fixing Loom¶

    • Reference Guide — grouped operator reference for commands, shortcuts, settings, logs, and runtime paths
    • CLI Reference — full command reference
    • Troubleshooting — symptom-first recovery steps for startup, sessions, worktrees, merge issues, and stale state
